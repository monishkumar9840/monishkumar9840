🚀 Featured Project
🧠 AI-Enhanced Memory Forensics Threat Analyzer

Python • Volatility 3 • Scikit-learn • Pandas • Matplotlib • Decision Tree

An AI-enhanced memory forensics project designed to automate the analysis
of volatile memory and assist investigators in identifying suspicious
process activity.

Key Features

🔎 Extracts process artifacts from memory dumps using Volatility 3
🧠 Uses a Decision Tree model for threat classification
📊 Implements a threat-scoring mechanism
🚨 Detects suspicious and hidden processes
📁 Generates structured CSV forensic reports
📈 Provides visualizations for security analysis

🎯 Goal: Reduce manual effort in memory forensic investigations by
combining traditional forensic analysis with machine learning.
